# SM Automotive Website

Professional B2B catalogue and lead-generation website for SM, an automotive control-cable manufacturing brand based in Delhi, India.

## Primary markets
- India
- UAE, including Dubai
- African export markets (specific destination countries to be confirmed)

## Initial scope
- Home
- Products and categories
- About and Manufacturing
- Contact and Request a Quote
- Reusable blog article layout

## Intended production platform
WordPress + Hello Elementor + Elementor Free + compatible add-ons.

## Development workflow
1. Prototype and review with Antigravity in this Git repository.
2. Validate the implementation approach against the available Novamira integration.
3. Review and approve the website.
4. Implement and test the approved experience in WordPress.
5. Verify SEO, responsive behaviour, forms, and conversion tracking.

## Important
The GitHub prototype is not considered WordPress-ready until its layouts, interactions, and assets have a verified implementation path in the target WordPress setup.
